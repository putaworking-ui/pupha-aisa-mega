Cross-Border Rule (มาตรฐาน 1.ก)
เมื่อทำงานข้ามประเทศ → ใช้ "strictest standard" ระหว่าง local law · CFA/ASCO standards · employer rules
• ถ้า local law < standards → ใช้ standards · disclose ส่วนที่ต่าง
• ถ้า local law > standards → ใช้ local law
Top Traps in T1
• MNPI: ใช้ได้แม้แค่ "mosaic" (รวมข้อมูล public หลายชิ้น) แต่ห้ามใช้ single non-public piece
• Trade allocation: ต้อง pro-rata fair · ห้าม allocate "ของดี" ให้บัญชีตัวเอง
• Gifts: รับได้ถ้าไม่กระทบ independence + disclose · refer fee ต้อง disclose
• Independence: Issuer-sponsored research ต้อง disclose + maintain objectivity
• Suitability: ต้อง update IPS ก่อนแนะนำ · ห้าม "one-size-fits-all"

Order of Action when Conflict

  1. Dissociate จากกิจกรรมผิด

  3. ถ้าไม่ได้รับการแก้ → resign (ห้ามอยู่และนิ่ง)
T2

GIPS — Global Investment Performance Standards

หลักการสำคัญ

  • Voluntary — บริษัทเลือกเอง · ต้อง declare compliance ตามรูปแบบที่กำหนด
  • Firm-wide compliance — ห้าม partial (เลือกบาง strategy)
  • Composite — รวม portfolio ที่บริหารใน strategy เดียวกัน เพื่อ fair comparison
  • Discretionary portfolios only — non-discretionary ห้ามรวม composite
  • Time-Weighted Return (TWR) เป็นมาตรฐาน (ไม่ใช่ MWR)

Return Formulas

G1Holding Period Return (HPR) / Single Period Return
$$HPR = \frac{P_1 - P_0 + D_1}{P_0} = \frac{P_1 + D_1}{P_0} - 1$$
$P_0$ = ราคาซื้อ · $P_1$ = ราคาขาย · $D_1$ = dividend/income · ใช้กับ single period
G2Time-Weighted Return (TWR) / Geometric chain link
$$TWR = [(1 + HPR_1)(1 + HPR_2)\cdots(1 + HPR_n)]^{1/n} - 1$$
GIPS standard — ตัดผลของ cash flow timing
• Geometric mean ของ sub-period returns
• วัด manager skill (ไม่นับ client's deposit/withdrawal timing)
G3Money-Weighted Return (MWR) = IRR of cash flows
$$0 = \sum_{t=0}^{n} \frac{CF_t}{(1 + MWR)^t}$$
• = IRR (Internal Rate of Return)
Trap: MWR ได้รับผลจาก cash flow timing → ไม่ fair compare manager
G4Arithmetic vs Geometric Mean
$$AM = \frac{\sum R_i}{n} \qquad GM = \left[\prod (1+R_i)\right]^{1/n} - 1$$
• AM ≥ GM เสมอ (equal เฉพาะเมื่อ R ทุกตัวเท่ากัน)
• AM = expected single-period (forecast)
• GM = realized compound (historical) — ใช้กับ multi-period
G5Asset-Weighted Composite Return
$$R_{composite} = \sum w_i \cdot R_i \quad \text{where } w_i = \frac{V_i}{\sum V_i}$$
Weight = market value (beginning หรือ average) · GIPS-required for composite reporting

T4

หลักการลงทุน (Investment Principles & Portfolio Theory)

Single Asset Risk

P1Variance & SD / ความแปรปรวน · ส่วนเบี่ยงเบนมาตรฐาน
$$\sigma^2 = \frac{\sum (R_i - \bar{R})^2}{n} \qquad \sigma = \sqrt{\sigma^2}$$
• Q37 lesson: ใช้ % form ตลอด · σ ใส่ %, σ² in "% squared"
• Sample vs Population: sample ใช้ $n-1$ ใน denominator
P2Coefficient of Variation (CV)
$$CV = \frac{\sigma}{\bar{R}}$$
• risk per unit of return · ต่ำกว่า = ดีกว่า
Trap: ถ้า $\bar{R}$ ติดลบ → CV interpretation พัง
P3Covariance
$$Cov_{1,2} = E[(R_1 - \bar{R_1})(R_2 - \bar{R_2})] = \rho_{1,2} \sigma_1 \sigma_2$$
หน่วย = % × % (scale-dependent) · ไม่มีขอบเขต · +/− บอกทิศทาง
P4Correlation Coefficient (ρ)
$$\rho_{1,2} = \frac{Cov_{1,2}}{\sigma_1 \sigma_2}$$
• ไม่มีหน่วย · range = $[-1, +1]$
• ρ = 0 ไม่ได้แปลว่าอิสระ — แค่ไม่มี linear relationship
ρ < 1 → diversification benefit · ρ = −1 → perfect hedge possible

Portfolio Risk

P52-Asset Portfolio Variance
$$\sigma_p^2 = w_1^2 \sigma_1^2 + w_2^2 \sigma_2^2 + 2 w_1 w_2 \rho_{12} \sigma_1 \sigma_2$$
• อย่าลืม √ ตอนจบ → $\sigma_p = \sqrt{\sigma_p^2}$
• ถ้าโจทย์ให้ Cov → ใช้ $2 w_1 w_2 Cov_{12}$
• ถ้า ρ = 1 → $\sigma_p = w_1 \sigma_1 + w_2 \sigma_2$ (max, ไม่มี benefit)
• ถ้า ρ < 1 → benefit
P63+ Asset Portfolio Variance (general)
$$\sigma_p^2 = \sum_i \sum_j w_i w_j \sigma_i \sigma_j \rho_{ij}$$
double sum · diagonal terms ($i=j$): $w_i^2 \sigma_i^2$ · off-diagonal: covariance pairs
P7Portfolio Expected Return
$$E(R_p) = \sum w_i \cdot E(R_i)$$
Weighted average ของ component expected returns
• Linear (ต่างจาก variance ที่ไม่ linear)

CAPM & Required Return

P8CAPM / Capital Asset Pricing Model
$$E(R_i) = R_f + \beta_i [E(R_m) - R_f]$$
• $R_f$ = risk-free rate · $\beta_i$ = systematic risk · $E(R_m) - R_f$ = Market Risk Premium
⭐ Trap: ไม่ใช้ dividend yield ใน CAPM
• β = 1 → market-like · β > 1 → aggressive · β < 1 → defensive
P9Beta (β)
$$\beta_i = \frac{Cov(R_i, R_m)}{\sigma_m^2} = \rho_{i,m} \cdot \frac{\sigma_i}{\sigma_m}$$
วัด systematic risk · diversification ลด specific risk · ลด systematic ไม่ได้

Performance Ratios

P10Sharpe Ratio
$$Sharpe = \frac{R_p - R_f}{\sigma_p}$$
Excess return per total risk · ใช้กับ portfolio ทั้ง diversified และไม่
P11Treynor Ratio
$$Treynor = \frac{R_p - R_f}{\beta_p}$$
Excess return per systematic risk · ใช้กับ diversified portfolio (specific risk หมด)
P12Jensen's Alpha (α)
$$\alpha_J = R_p - [R_f + \beta_p(R_m - R_f)]$$
Actual − CAPM predicted · α > 0 → outperform · วัด manager skill
P13Sortino Ratio
$$Sortino = \frac{R_p - R_f}{\sigma_{downside}}$$
Sharpe variation · denominator = downside SD only (ใช้แค่ negative returns)
P14Information Ratio
$$IR = \frac{R_p - R_{benchmark}}{\sigma(R_p - R_{benchmark})} = \frac{Active\ Return}{Tracking\ Error}$$
Excess return vs benchmark per tracking error · วัด active management skill
Performance Ratio Summary (เลือก ratio ตามสถานการณ์)
• Diversified portfolio → Treynor, Jensen
• Non-diversified / single asset → Sharpe
• Downside-focused investor → Sortino
• Active manager vs benchmark → Information Ratio
T5

การเงินธุรกิจ (Corporate Finance)

Cost of Capital

F1WACC / Weighted Average Cost of Capital
$$WACC = \frac{E}{V} r_e + \frac{D}{V} r_d (1-T) + \frac{P}{V} r_p$$
• $V = D + E + P$ (Total Capital)
• Debt ใช้ after-tax cost (tax shield)
• Equity, Preferred ไม่มี tax adjustment
• Weight = market value (ideally) ไม่ใช่ book value
F2Cost of Equity (3 methods)
Method 1 (CAPM): $$r_e = R_f + \beta(R_m - R_f)$$
Method 2 (DDM): $$r_e = \frac{D_1}{P_0} + g$$
Method 3 (Build-up): $$r_e = R_f + ERP + \text{size premium} + \text{specific risk}$$
• DDM method: ต้องมี stable dividend + g คงที่
• Build-up: สำหรับ private company / illiquid
• CAPM: most common · ต้องมี β (public stock)
F3Cost of Debt (after-tax)
$$r_d(1-T) = YTM \times (1 - Tax\ rate)$$
ใช้ YTM ของ debt ที่ existing · ไม่ใช่ coupon rate · tax shield ลด effective cost

Leverage

F4DOL / Degree of Operating Leverage
$$DOL = \frac{Q(P-V)}{Q(P-V) - F} = \frac{Contribution\ Margin}{EBIT} = \frac{\%\Delta EBIT}{\%\Delta Sales}$$
• Q = quantity · P = price · V = variable cost/unit · F = fixed cost
• วัด sensitivity ของ EBIT ต่อ Sales
• DOL สูง = fixed cost สูง = ปังก็ปังมาก เจ๊งก็เจ๊งหนัก
F5DFL / Degree of Financial Leverage
$$DFL = \frac{EBIT}{EBIT - Interest} = \frac{\%\Delta EPS}{\%\Delta EBIT}$$
วัด sensitivity ของ EPS ต่อ EBIT · DFL สูง = หนี้สูง = leverage งบมาก
F6DCL (Total Leverage)
$$DCL = DOL \times DFL = \frac{\%\Delta EPS}{\%\Delta Sales}$$
Combined effect · วัด total sensitivity ของ EPS ต่อ Sales

Capital Budgeting

F7NPV / Net Present Value
$$NPV = \sum_{t=0}^{n} \frac{CF_t}{(1+r)^t} = -Initial\ Investment + \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t}$$
• NPV > 0 → accept · NPV < 0 → reject
• Mutually exclusive projects → เลือก NPV สูงสุด
F8IRR / Internal Rate of Return
$$0 = \sum_{t=0}^{n} \frac{CF_t}{(1 + IRR)^t}$$
• IRR > required return → accept
Trap: NPV และ IRR อาจให้ ranking ต่างกัน — เชื่อ NPV (เพราะ IRR assumes reinvest ที่ IRR rate ไม่จริง)
F9Payback Period
$$Payback = \frac{Initial\ Investment}{Annual\ CF}$$
• วัดเวลาคืนทุน (ไม่นับ time value of money)
• Discounted Payback = นับ TVM
F10Profitability Index (PI)
$$PI = \frac{PV\ of\ future\ CFs}{Initial\ Investment} = 1 + \frac{NPV}{Initial\ Investment}$$
• PI > 1 → accept · PI < 1 → reject
• ใช้กับ capital rationing (จำกัดงบ) — เลือก PI สูงสุด

Working Capital & Cash Management

F11EOQ / Economic Order Quantity
$$EOQ = \sqrt{\frac{2 D S}{H}}$$
D = annual demand · S = ordering cost/order · H = holding cost/unit/year · minimize total cost
F12Cash Conversion Cycle (CCC)
$$CCC = DIO + DSO - DPO$$
• DIO = Days Inventory Outstanding
• DSO = Days Sales Outstanding (collect AR)
• DPO = Days Payable Outstanding (delay AP)
• CCC ต่ำ = ดี · cash หมุนเวียนเร็ว
F13Breakeven Analysis
$$Q_{BE} = \frac{Fixed\ Cost}{Price - Variable\ Cost} = \frac{F}{P - V}$$
หน่วยที่ขายแล้วเสมอตัว (EBIT = 0) · เพิ่ม "+Interest" ใน F สำหรับ leveraged breakeven

$$Quick\ Ratio = \frac{CA - Inventory - Prepaid}{CL}$$

เรียงเข้มงวด: Cash < Quick < Current · Inventory เป็น CA แต่ตัดออกใน Quick

Leverage (โครงสร้างทุน)

$$D/A = \frac{Total\ Debt}{Total\ Assets} \qquad D/E = \frac{Total\ Debt}{Equity}$$
$$EM = \frac{TA}{Equity} = 1 + \frac{D}{E}$$
$$TIE = \frac{EBIT}{Interest\ Expense}$$
⭐ Top Trap: EM ≠ D/E · EM = 1 + D/E เมื่อ D/E ใช้ Total Debt
TIE ใช้ EBIT ไม่ใช่ NI · สูง = safe

Profitability (ความสามารถทำกำไร)

$$Gross\ Margin = \frac{Gross\ Profit}{Sales} \qquad Operating\ Margin = \frac{EBIT}{Sales}$$
$$Net\ Margin = \frac{NI}{Sales} \qquad ROA = \frac{NI}{TA}$$
$$ROE = \frac{NI}{Equity}$$
DuPDuPont Decomposition (ROE)
$$ROE = NPM \times AT \times EM \quad \text{(3-component)}$$
$$ROE = ROA \times EM \quad \text{(2-component)}$$
$$ROE = NPM \times Equity\ Turnover \quad \text{(variant)}$$
• ทุก form valid mathematically (algebra ตัด terms ลงตัว)
• AISA ขอ 3-comp เป็น default · 2-comp เมื่อโจทย์ให้ ROA ตรงๆ

Efficiency (ประสิทธิภาพ)

$$Asset\ Turnover = \frac{Sales}{TA} \qquad Inventory\ Turnover = \frac{COGS}{Avg\ Inventory}$$
$$Receivables\ Turnover = \frac{Sales}{Avg\ AR} \qquad Payables\ Turnover = \frac{COGS}{Avg\ AP}$$
$$DIO = \frac{365}{IT} \qquad DSO = \frac{365}{RT} \qquad DPO = \frac{365}{PT}$$
DIO + DSO − DPO = Cash Conversion Cycle

Valuation — DDM Family

E1Gordon Growth Model (Constant DDM)
$$P_0 = \frac{D_1}{r - g}$$
$D_1 = D_0(1+g)$ · ใช้เมื่อ g คงที่ตลอด · ต้อง g < r
บริษัท mature, dividend สม่ำเสมอ
E22-Stage DDM
$$P_0 = \sum_{t=1}^{n} \frac{D_t}{(1+r)^t} + \frac{P_n}{(1+r)^n}$$
$$P_n = \frac{D_{n+1}}{r - g_2}$$
⭐ Terminal value ใช้ $k - g$ ไม่ใช่ $k + g$
High growth (g₁) n ปีแรก → stable growth (g₂) ตลอดไป
E3H-Model
$$P_0 = \frac{D_0 (1+g_L) + D_0 \cdot H \cdot (g_S - g_L)}{r - g_L}$$
• $g_S$ = short-term growth · $g_L$ = long-term growth · H = half of high-growth period
• Growth ลด linearly จาก $g_S$ → $g_L$ ตลอด 2H ปี (ไม่ใช่ step change)

FCFE / FCFF

E4FCFE Gordon
$$P_0 = \frac{FCFE_1}{r_e - g}$$
discount rate = cost of equity ($r_e$) · ได้ equity value ตรงๆ
E5FCFF Gordon
$$Firm\ Value = \frac{FCFF_1}{WACC - g}$$
$$Equity\ Value = Firm\ Value - Debt\ Value$$
⭐ Top trap: WACC ไม่ใช่ ke
ได้ firm value · ลบหนี้ → equity
E6FCFE จาก NI
$$FCFE = NI + NCC - FCInv - WCInv + Net\ Borrowing$$
• NCC = Non-Cash Charges (Depreciation, Amortization)
• FCInv = Fixed Capital Investment (CapEx)
• WCInv = Change in Working Capital
• Net Borrowing = New Debt − Debt Repaid
E7FCFF จาก NI
$$FCFF = NI + NCC + Int(1-T) - FCInv - WCInv$$
$$FCFF = EBIT(1-T) + Dep - FCInv - WCInv$$
$$FCFF = FCFE + Int(1-T) - Net\ Borrowing$$
• บวกกลับ Int(1−T) เพราะ FCFF = ก่อนจ่ายเจ้าหนี้
• ไม่มี Net Borrowing (debt-level neutral)

Relative Valuation (Multiples)

E8Justified Leading P/E
$$\frac{P_0}{E_1} = \frac{Payout}{r - g}$$
$g = ROE \times b$ · b = retention = 1 − payout · Leading = E ปีหน้า
E9Justified Trailing P/E
$$\frac{P_0}{E_0} = \frac{Payout \times (1+g)}{r - g}$$
Trailing = E ล่าสุด → ต้อง × (1+g) ใน numerator
E10P/B (Price-to-Book)
$$\frac{P_0}{B_0} = \frac{ROE - g}{r - g}$$
Justified P/B · BV ต้อง positive (ใช้ไม่ได้ถ้า equity negative)
E11P/S (Price-to-Sales)
$$\frac{P_0}{S_0} = \frac{NPM \times Payout \times (1+g)}{r - g}$$
ใช้กับ cyclical / loss-making companies (sales ยังบวก แม้ NI ลบ)
E12EV/EBITDA
$$EV = Market\ Cap + Debt - Cash$$
• EBITDA = Earnings Before Interest, Tax, Depreciation, Amortization
• ใช้เปรียบเทียบ capital structure ต่างกัน (ไม่กระทบจาก leverage)

Bond Pricing & Yields

B1Bond Price (PV)
$$P = \sum_{t=1}^{n} \frac{C}{(1+y)^t} + \frac{F}{(1+y)^n}$$
C = coupon · F = face value · y = YTM/period · n = number of periods
Semi-annual: ใช้ C/2, y/2, n × 2
B2Price ↔ Yield Relationship
$$\text{Price} \uparrow \iff \text{Yield} \downarrow \quad (\text{inverse relationship})$$

Duration & Convexity

B4Macaulay Duration
$$Mac\ D = \sum \frac{t \cdot CF_t / (1+y)^t}{P}$$
weighted average time to receive cash flows (ปี)
• Zero-coupon bond: Mac D = maturity
• Coupon bond: Mac D < maturity
B5Modified Duration
$$Mod\ D = \frac{Mac\ D}{1 + y}$$
วัด price sensitivity ต่อ yield
• $\%\Delta P \approx -Mod\ D \times \Delta y$
B6Effective Duration
$$Eff\ D = \frac{P_{-} - P_{+}}{2 \times P_0 \times \Delta y}$$
• $P_-$ = price ที่ yield ลด · $P_+$ = price ที่ yield เพิ่ม
• ใช้กับ callable / putable / option-embedded bonds
B7Convexity (formula)
$$Convexity = \frac{(P_+) + (P_-) - 2P_0}{2 P_0 \, (\Delta y)^2}$$
P₊ = price เมื่อ yield ↓ Δy · P₋ = price เมื่อ yield ↑ Δy · P₀ = price ปัจจุบัน
curvature measure · หน่วยเป็น years² · ค่านี้ไปใส่ใน B8 ต่อ
B8Convexity Adjustment
$$\%\Delta P \approx -Mod\ D \times \Delta y + \frac{1}{2} \times Convexity \times (\Delta y)^2$$
• Duration เป็น linear approximation · Convexity แก้ curvature
• Convexity เพิ่ม upside · ลด downside = นักลงทุนชอบ
